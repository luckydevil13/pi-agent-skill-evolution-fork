# 02: Модуль «skill-package»: имена, пути, реестр

**What to build:** Все операции над пакетом навыка как над файловой сущностью собираются в один module: валидация имён навыков, безопасное разрешение путей внутри пакета (отклонение абсолютных путей, `..`, символьных ссылок наружу), хэширование файлов, обнаружение навыков (discover) и разрешение по имени/scope (resolve). Расширение продолжает работать без изменений поведения; наружу из модуля торчит узкий интерфейс вместо разрозненных helper-функций.

**Blocked by:** 01 (нужны харнесс и конвенция импортов; правки того же монофайла идут последовательно)

**Status:** done

- [ ] Модуль не имеет runtime-зависимостей от pi/typebox
- [ ] Тесты эскейпов на временных директориях зелёные: `..` в относительном пути, абсолютный путь, символьная ссылка, ведущая наружу из пакета — всё отклоняется с понятной ошибкой
- [ ] Тесты валидации имён: длина, алфавит, дефисы, пустое имя
